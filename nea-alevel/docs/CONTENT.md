# A level NEA practice (Pearson Edexcel A level D&T Product Design 9DT0, Component 2)

A3 landscape practice folder built with `../nea-kit` (studio look). Students do a short project set in `config.js → project`.

- **Sheets (27):** intro ×2 · one to four sheets per assessment grid (11 grids, 120 marks) · self-review.
- **Boxes, marks, guidance and layouts:** `rubric.js` (grids 1–11: 9, 15, 9, 9, 9, 9, 12, 6, 12, 18, 12 = 120). Intro/outro sheets: `pages/sheets.js`.
- **Teacher only:** 📐 NEA marks tab: indicative marks per section, boxes filled, words, photos/sketches with thumbnails, last edit. `hideScores: true`.
- **Lock:** `config.js → gateHash`. Light protection only. Hidden from the homepage.
- After changing sheets: `python3 book-kit/tools/make_manifest.py nea-alevel`.
